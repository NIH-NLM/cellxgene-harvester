cellxgene-harvester Documentation
==================================

Harvest, filter, and count normal cells of the CellxGene datasets using
ontology-based filtering (UBERON tissue, PATO/MONDO disease, HsapDv age).
The cells are read from the h5ad file of each dataset; the
`CellxGene Census <https://chanzuckerberg.github.io/cellxgene-census/>`_ is another source.

Architecture and engineering by Anne Deslattes Mays (NIH-NLM) with
human-prompted AI-assisted development using `Claude <https://claude.ai>`_ (Anthropic).
