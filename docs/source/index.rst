cellxgene-harvester Documentation
==================================

Harvest, filter, and count normal cells from the
`CellxGene Census <https://chanzuckerberg.github.io/cellxgene-census/>`_
using ontology-based filtering (UBERON tissue, PATO/MONDO disease, HsapDv age).

Architecture and engineering by Anne Deslattes Mays (NIH-NLM) with
human-prompted AI-assisted development using `Claude <https://claude.ai>`_ (Anthropic).
